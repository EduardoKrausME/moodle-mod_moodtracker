# Changelog

This changelog documents only the two most recent published GitHub releases. Each entry reflects the changes between that release tag and the immediately preceding published tag. Changes made later on `master` are not included.

## 1.1.7 - 2026-10-15

### Changed

- Updated the GitHub Actions CI database service from PostgreSQL 16 to PostgreSQL 17.
- Updated the MariaDB CI service from version 10 to 11.4, including revised startup environment variables and the MariaDB health-check command.
- Added `pix/icon.png` and reorganized the SVG logo asset under `pix/monologo.svg`.
- Updated the plugin release identifier from `1.1.6` to `1.1.7` and its build number from `2026101200` to `2026101500`.

No changes to the plugin's mood-tracking functionality were identified between the published `1.1.6` and `1.1.7` tags.

[Compare 1.1.6...1.1.7](https://github.com/EduardoKrausME/moodle-mod_moodtracker/compare/1.1.6...1.1.7)

## 1.1.6 - 2026-10-12

### Changed

- Updated the Moodle version used by the PHP 8.3 CI matrix entry from `MOODLE_502_STABLE` (Moodle 5.2) to `MOODLE_503_STABLE` (Moodle 5.3). The Moodle 4.5 test entry was retained.
- Updated the plugin release identifier from `1.1.5` to `1.1.6` and its build number from `2026100801` to `2026101200`.

No changes to the plugin's mood-tracking functionality were identified between the published `1.1.5` and `1.1.6` tags.

[Compare 1.1.5...1.1.6](https://github.com/EduardoKrausME/moodle-mod_moodtracker/compare/1.1.5...1.1.6)
