# Moodle Mood Tracker activity

`mod_moodtracker` provides a quick class mood check-in activity for Moodle.

Students select one mood from a small set of options, while teachers can view an aggregated class dashboard. Teachers may configure whether students can change their response after submitting it.

## Installation

Copy the `moodtracker` directory to `mod/moodtracker` in the Moodle installation and complete the Moodle upgrade process from Site administration.

## Privacy

The activity stores the user's current mood response for each activity instance. Access to the aggregated report is controlled by Moodle capabilities.
